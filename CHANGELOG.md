# Changelog

## Initial repository import

This repository imports the existing local BeltTwin prototype and its recorded
acceptance evidence. Commit timestamps reflect this import, not earlier work.

- Conveyor foundation, five splice markers and deterministic encoder tracking.
- Synchronized synthetic camera, 24-channel MFL, profile and tension data.
- Immutable per-splice healthy fingerprints and persistent inspection history.
- Explainable anomaly detection and six-stage S03 degradation scenario.
- Current-condition/history fusion, health states and native demonstration HUD.
- 76 local automated tests and recorded Phase 1–6 live regression checks.
- Checkout-portable Windows test runner and GitHub Actions configuration.

No trained model, measured F1 score, physical inspection validation, predictive
maintenance or Phase 8 functionality is included.
